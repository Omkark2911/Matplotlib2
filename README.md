# Matplotlib2

This repository contains beginner-friendly Python programs demonstrating different types of charts using matplotlib.

Charts Included
 - Line Plot
 - Bar Chart
 - Pie Chart
 - Histogram
 - Scatter Plot

* Subplot functions
* Saving figures to .png, .jpg, .pdf, etc

What You'll Learn
 -Creating different charts
 - Adding titles and labels
 - Customizing graphs
 - Basic data visualization with Python
